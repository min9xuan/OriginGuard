# M3.2 多确定性媒体 Skill

## 目标

在不引入 LLM Planner、RAG 或检测模型的前提下，让 Agent Harness 从单一 Tool 调用升级为可追踪的多 Skill 流水线，并验证 Skill 版本、Tool 白名单、策略检查、预算和 Checkpoint 能覆盖连续执行。

## 固定计划

```text
Fake Planner
→ verify_media_integrity@1.0.0
→ extract_image_metadata@1.0.0
→ compare_perceptual_similarity@1.0.0
→ 结构化结论（INCONCLUSIVE）
```

### verify_media_integrity

调用 `media.verify_integrity`，从 MinIO 重新读取每个媒体文件，核验登记 SHA-256、字节数、登记 MIME 与真实文件签名。输出 `FILE_INTEGRITY` Observation。

### extract_image_metadata

调用 `media.extract_image_metadata`，重新解码媒体并输出实际格式、宽高、像素量和有限 EXIF 摘要。输出 `IMAGE_METADATA` Observation。EXIF 缺失不解释为伪造或 AIGC。

### compare_perceptual_similarity

调用 `media.compare_perceptual_similarity`，为案件内图片计算 dHash64 并执行两两汉明距离比较：距离 0 为 `IDENTICAL_DHASH`，1 至 5 为 `NEAR_DUPLICATE`，其余为 `DIFFERENT`。输出 `PERCEPTUAL_SIMILARITY` Observation。相似度不等于来源相同，也不是 AIGC 证据。

## Harness 行为

每个 Skill 都会产生 `SKILL_SELECTED`、`TOOL_CALLED`、`OBSERVATION_RECORDED` 和 `CHECKPOINT_SAVED` Trace。三个 Skill 加最终结论共消耗七步预算。任一步失败都会使任务进入 `FAILED`，并保存安全化错误信息和审计记录。

## 当前限制

- Planner 顺序仍为固定代码，不理解自然语言目标；
- 仅支持 JPEG/PNG；
- 没有 C2PA、AIGC 分类、篡改定位和 RAG；
- Observation 是调查材料，不会自动推进案件或替代人工审核。
