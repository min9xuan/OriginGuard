# M6.3 图像篡改定位

## 目标

OriginGuard 在既有“整图 AIGC 倾向”之外增加独立的局部篡改定位。首版采用 Mesorch，回答“哪些像素区域呈现出可疑编辑响应”，不回答“是谁编辑”“使用了什么软件”，也不把响应分数解释为司法意义上的篡改概率。

## 执行链路

```text
Agent 计划
  -> localize_image_manipulation Skill
  -> model.localize_image_manipulation Tool
  -> ForensicModelRegistry（MANIPULATION_LOCALIZATION）
  -> MesorchModelAdapter
  -> model-api /v1/forensics/manipulation/localize
  -> MANIPULATION_LOCALIZATION Observation
```

任务详情页始终显示当前图片的定位视口，调查员可在叠加图、热力图和二值掩码之间切换。多图任务沿用左右切换，不把每张图片纵向重复展开。

## 安装

1. 从 Mesorch 官方仓库 README 提供的权重地址取得 `mesorch-98.pth`。
2. 在项目根目录运行：

```powershell
.\scripts\setup-mesorch.ps1 -CheckpointPath D:\path\to\mesorch-98.pth
```

脚本固定官方源码提交 `33454cb6d595267033ce1109b62ad373110678db`，安装 `model-api[mesorch]` 可选依赖，将权重放入 `.runtime/models/mesorch/`，并写入本地 SHA-256 sidecar。源码、模型和缓存均不提交到 Git。

可在 `.env` 覆盖：

- `MESORCH_SOURCE_PATH`
- `MESORCH_CHECKPOINT_PATH`
- `MESORCH_DEVICE=auto|cpu|cuda`
- `MESORCH_MASK_THRESHOLD`
- `MESORCH_MIN_AREA_RATIO`
- `MESORCH_TIMEOUT`

未安装源码或权重时，模型 API 仍可启动；该 Skill 会记录 `UNAVAILABLE`，Agent 保留 AIGC、C2PA 和其他观察继续运行。

## 输出与解释

- `tamperedProbability`：响应最高 1% 像素的均值，用于界面排序，不是经校准的真实性概率。
- `tamperedAreaRatio`：超过当前掩码阈值的像素面积占比。
- `regions`：过滤微小连通域后的候选矩形区域。
- `maskArtifact`、`heatmapArtifact`、`overlayArtifact`：保存到 Agent 工件存储，通过鉴权接口读取，不把 Base64 写入数据库。
- `calibrated=false`：首版明确标记阈值未使用 OriginGuard 业务验证集校准。

## 后续验证

下一阶段使用 IMDL-BenCo 的数据与指标协议建立固定评测集，至少记录像素级 F1、IoU、AUC、图像级 F1、吞吐和显存占用。结果应按媒体类型、篡改类型、压缩/缩放和截图等退化方式分层报告，不能只给一个总分。
