# M4.3 RAG 知识扩展

## 目标

OriginGuard 在用户点击“检索候选知识”时访问 OpenAlex，只读取论文元数据与摘要，不下载 PDF、附件、数据集或模型权重。候选结果不会直接进入 Agent RAG。

## 数据流

```text
RAG 知识扩展
→ 选择主题、会议/期刊和年份
→ OpenAlex 元数据检索
→ 会议/期刊白名单校验与去重
→ 生成 EXTERNAL / DRAFT 知识草稿
→ 人工核对来源并编辑
→ 发布、切片与 Embedding
→ Agent RAG 可检索
```

## 来源与优先级

- `TENANT`：租户自行维护的知识，默认优先级 100。
- `BUILTIN`：为后续内置知识包预留。
- `EXTERNAL`：OpenAlex 学术候选生成的草稿，默认优先级 40。

最终排序仍以语义和关键词相关性为主，来源优先级只占 15%，避免不相关的高优先级文档压过相关内容。

## OpenAlex 限流

匿名 OpenAlex 搜索可能临时限流。可申请免费的 API Key，并在启动后端前设置：

```powershell
$env:OPENALEX_API_KEY='your-free-key'
```

Key 只用于元数据请求，不会触发论文 PDF 下载。
