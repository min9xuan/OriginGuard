# M3.3 Agent Observation、正式证据与审核闭环

## 目标

把 Agent Harness 的结构化输出接入真实调查业务，同时避免把确定性 Tool 的有限观察误用为 AIGC 自动判定。

## 数据流

```text
Agent Tool
→ Agent Observation（候选调查材料）
→ 调查员明确执行“纳入案件证据”
→ Investigation Evidence（正式、只追加）
→ 审核员勾选引用证据
→ Review Decision
```

## 核心约束

- 只有分派的调查员能在 `INVESTIGATING` 状态纳入 Observation；
- Observation 必须来自同一租户、同一案件、已完成的 AgentTask；
- 同一个 Observation 只能纳入一次；
- Agent 证据固定为 `INCONCLUSIVE`、`LOW`，并提示“不构成 AIGC 结论”；
- 审核员必须引用至少一条正式案件证据才能批准或驳回；
- 引用的证据必须属于当前案件；
- 审核决定、引用证据 ID、操作者与时间全部持久化并进入审计日志。

## 数据库

V7 为 `investigation_evidence` 增加 `source_observation_id`，并建立唯一索引；新增 `review_evidence_reference` 保存审核任务与正式证据的多对多引用。

## 当前边界

正式证据表示“调查员确认该 Observation 值得交给审核员参考”，不表示内容已经被证明真实、合成或篡改。最终决定仍由独立审核员结合人工观察和 Agent 辅助事实作出。
